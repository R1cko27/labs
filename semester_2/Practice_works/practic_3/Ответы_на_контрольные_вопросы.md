# Контрольные вопросы и ответы

## 1. Что такое файл?

Файл — это именованная область памяти на диске, предназначенная для хранения данных. Файл содержит последовательность байтов и имеет имя, которое позволяет его идентифицировать и получать к нему доступ. Файлы используются для постоянного хранения информации, которая сохраняется даже после завершения программы.

## 2. Что такое режим (mode) файла?

Режим файла — это набор прав доступа, определяющих, какие операции допустимы с файлом. В операционных системах режим состоит из:
- **Прав чтения (read)** — возможность читать содержимое файла
- **Прав записи (write)** — возможность изменять или дополнять файл
- **Прав выполнения (execute)** — возможность запустить файл как программу

Примеры: `_S_IREAD` (чтение), `_S_IWRITE` (запись).

## 3. Как задаются возможные операции при открытии файла?

Возможные операции задаются с помощью флагов (битовых масок) при вызове функции `_open()`:

```c
int fd = _open(pathname, flags, mode);
```

**Основные флаги:**
- `_O_RDONLY` — открыть только для чтения
- `_O_WRONLY` — открыть только для записи
- `_O_RDWR` — открыть для чтения и записи
- `_O_CREAT` — создать файл, если он не существует
- `_O_TRUNC` — очистить файл при открытии
- `_O_APPEND` — добавлять в конец файла
- `_O_EXCL` — ошибка, если файл уже существует

Флаги комбинируются с помощью оператора `|` (побитовое ИЛИ).

## 4. Что будет если открыть файл, отсутствующий на диске?

Если открыть несуществующий файл без флага `_O_CREAT`:
- Функция `_open()` вернет значение **-1** (ошибка)
- Переменная `errno` будет установлена в значение, обозначающее ошибку (обычно `ENOENT` — файл не найден)
- Можно получить описание ошибки через `strerror(errno)`

Пример:
```c
fd = _open("nonexistent.bin", _O_RDONLY);
if (fd == -1) {
    printf("Ошибка: %s\n", strerror(errno));
}
```

## 5. Что будет если повторно создать файл (который уже есть на диске)?

**При использовании `_O_CREAT | _O_TRUNC`:**
- Файл будет перезаписан (очищен)
- Старые данные будут удалены

**При использовании `_O_CREAT | _O_EXCL`:**
- Функция вернет **-1** (ошибка)
- `errno` будет установлена в `EEXIST` (файл уже существует)
- Файл не будет изменен

## 6. Что такое дескриптор файла?

Дескриптор файла — это **целое число**, которое операционная система использует для идентификации открытого файла внутри процесса. Это не путь к файлу, а внутренний индекс в таблице открытых файлов процесса.

**Стандартные дескрипторы:**
- `0` — stdin (стандартный ввод)
- `1` — stdout (стандартный вывод)  
- `2` — stderr (стандартная ошибка)

**Примеры:**
- Функция `_open()` возвращает дескриптор
- Значение **-1** означает ошибку открытия
- Дескриптор используется в функциях `_read()`, `_write()`, `_close()`

## 7. Какие операции по работе с файлом в небуферизованном режиме вы использовали?

**Небуферизованные операции (работают на уровне ОС):**

- **`_open(path, flags, mode)`** — открытие файла, возвращает дескриптор
- **`_read(fd, buffer, count)`** — чтение `count` байтов из файла в буфер
- **`_write(fd, buffer, count)`** — запись `count` байтов из буфера в файл
- **`_lseek(fd, offset, whence)`** — перемещение файлового указателя
- **`_close(fd)`** — закрытие файла

Эти функции работают без буферизации библиотеки (хотя ОС может использовать свою буферизацию).

## 8. Что записывается в файл при использовании функции write или fwrite?

При использовании `_write()` или `fwrite()` в файл записывается **ровно то количество байтов**, которое указано:

```c
_write(fd, buffer, sizeof(buffer));  // записит sizeof(buffer) байтов
```

**Что именно записывается:**
- Для примитивных типов: побайтовое представление значения
- Для массивов: все элементы подряд
- Для структур: все поля структуры подряд (включая выравнивания памяти)

**Пример:**
```c
int value = 123456789;
_write(fd, &value, sizeof(int));  // записываются 4 байта (на большинстве систем)
```

## 9. Что считывается из файла при использовании функции read или fread?

При использовании `_read()` или `fread()` из файла считывается **точное количество байтов**, которое указано (или до конца файла):

```c
int bytes_read = _read(fd, buffer, count);
```

**Возвращаемое значение:**
- Количество реально прочитанных байтов
- **0**, если достигнут конец файла
- **-1**, если произошла ошибка

**Пример:**
```c
int read_value;
int bytes = _read(fd, &read_value, sizeof(int));
if (bytes == sizeof(int)) {
    // Успешно прочитано значение
}
```

## 10. Что такое файловый указатель?

Файловый указатель — это **позиция** (номер байта) в файле, с которой будет выполнена следующая операция чтения или записи.

**Характеристики:**
- Каждый открытый файл имеет свой файловый указатель
- Начальное значение:
  - **0** (начало файла) для режима чтения
  - **конец файла** для режима добавления (`_O_APPEND`)
- После каждой операции чтения/записи указатель автоматически смещается на количество прочитанных/записанных байтов
- Можно явно перемещать с помощью `_lseek()`

## 11. Как можно перемещать файловый указатель?

Файловый указатель перемещается с помощью функции **`_lseek()`**:

```c
long new_pos = _lseek(fd, offset, whence);
```

**Параметры:**
- `fd` — дескриптор файла
- `offset` — смещение в байтах (может быть отрицательным)
- `whence` — точка отсчета:
  - `SEEK_SET` — от начала файла
  - `SEEK_CUR` — от текущей позиции
  - `SEEK_END` — от конца файла

**Примеры:**
```c
_lseek(fd, 0, SEEK_SET);           // на начало файла
_lseek(fd, -10, SEEK_END);         // за 10 байт до конца
_lseek(fd, sizeof(int), SEEK_CUR); // на sizeof(int) вперед
```

## 12. Как узнать текущую позицию файлового указателя?

Текущая позиция определяется с помощью **`_lseek()` с нулевым смещением**:

```c
long current_pos = _lseek(fd, 0, SEEK_CUR);
```

Это перемещает указатель на 0 байт относительно текущей позиции (остается на месте), но возвращает текущую позицию.

**Пример:**
```c
long pos = _lseek(fd, 0, SEEK_CUR);
printf("Текущая позиция: %ld\n", pos);
```

## 13. Какие операции по работе с файлом в буферизованном режиме вы использовали?

**Буферизованные операции (используют FILE*):**

- **`fopen(path, mode)`** — открытие файла, возвращает указатель FILE*
- **`fread(buffer, size, count, file)`** — чтение структурированных данных
- **`fwrite(buffer, size, count, file)`** — запись структурированных данных
- **`fprintf(file, format, ...)`** — форматированная запись в файл
- **`fgets(buffer, size, file)`** — чтение строки из файла
- **`fseek(file, offset, whence)`** — перемещение указателя
- **`ftell(file)`** — получение текущей позиции
- **`fclose(file)`** — закрытие файла

Эти функции используют дополнительный буфер в памяти для оптимизации операций.

## 14. Что такое FILE*? Как используется такой указатель?

**FILE*** — это **указатель на структуру FILE**, которая содержит информацию о буферизованном файле:
- Указатель на дескриптор файла
- Буфер в памяти
- Текущая позиция в буфере
- Режим открытия файла
- Состояние ошибок

**Использование:**
```c
FILE* file = fopen("file.txt", "r");
if (file == NULL) {
    printf("Ошибка открытия\n");
}
// работа с файлом
fclose(file);
```

**Отличие от дескриптора:**
- Дескриптор — это просто число (int)
- FILE* — это структура с метаинформацией для буферизированного доступа

## 15. Что записывается в файл при использовании функции fprintf?

Функция `fprintf()` записывает **форматированный текст**:

```c
fprintf(file, "%s;%s;%d;%s\n", group_name, direction, year, level);
```

**Что записывается:**
- Строка с подставленными значениями переменных
- Все управляющие символы (`\n`, `\t` и т.д.) обрабатываются как текст
- Результат записывается как текстовые ASCII-символы (не бинарные данные)

**Пример результата:**
```
AP-226;IS;2022;B
AP-326;PI;2023;B
```

## 16. Как работает функция fgets (проанализируйте возможные ситуации)?

Функция `fgets()` читает **строку** из файла:

```c
char* result = fgets(buffer, max_size, file);
```

**Параметры:**
- `buffer` — буфер для хранения строки
- `max_size` — максимальное количество символов
- `file` — указатель на FILE

**Возвращаемое значение:**
- Указатель на `buffer` при успехе
- `NULL` при ошибке или конце файла

**Возможные ситуации:**

1. **Нормальное чтение:**
   ```c
   // Содержимое файла: "Hello\n"
   fgets(line, 256, file);
   // line = "Hello\n"
   ```
   Символ `\n` сохраняется в буфере!

2. **Строка длиннее max_size:**
   ```c
   // В файле: "VeryLongStringHere\n"
   fgets(line, 10, file);
   // line = "VeryLongS" (max_size-1 символов, т.к. \0 в конце)
   ```

3. **Конец файла:**
   ```c
   fgets(line, 256, file);
   // Если EOF, возвращает NULL
   ```

4. **Пустая строка в файле:**
   ```c
   // Содержимое файла: "\n"
   fgets(line, 256, file);
   // line = "\n" (только символ новой строки)
   ```

5. **Ошибка при чтении:**
   ```c
   if (fgets(line, 256, file) == NULL) {
       // Проверяем: feof(file) или ferror(file)
   }
   ```

**Важно:** `fgets()` сохраняет символ `\n`, поэтому обычно нужно его удалить:
```c
line[strcspn(line, "\n")] = 0;  // удаляем \n, если есть
```

## 17. Как выполняется сериализация бинарного объекта (на примере структуры)?

Сериализация — это преобразование объекта в памяти в последовательность байтов для сохранения в файл.

**Для структуры:**

```c
typedef struct {
    char group_name[11];
    StudyDirection direction;
    int enrollment_year;
    EducationLevel level;
} StudyGroup;

StudyGroup group;
init_study_group(&group, "AP-526", PI, 2025, B);

// Сериализация (запись в бинарный файл)
int fd = _open("groups.bin", _O_WRONLY | _O_CREAT | _O_BINARY);
_write(fd, &group, sizeof(StudyGroup));
_close(fd);
```

**Как это работает:**
1. Функция `sizeof(StudyGroup)` подсчитывает общий размер структуры (включая выравнивание)
2. Структура копируется в файл как последовательность байтов
3. Все поля записываются в их естественном представлении в памяти (little-endian или big-endian в зависимости от архитектуры)
4. На диске получается бинарный файл, который нельзя открыть текстовым редактором

## 18. Как выполняется десериализация бинарного объекта (на примере структуры)?

Десериализация — это обратный процесс: чтение байтов из файла и восстановление объекта в памяти.

```c
StudyGroup read_group;

// Десериализация (чтение из бинарного файла)
int fd = _open("groups.bin", _O_RDONLY | _O_BINARY);
int read_bytes = _read(fd, &read_group, sizeof(StudyGroup));

if (read_bytes == sizeof(StudyGroup)) {
    // Успешно восстановлена структура
    print_study_group(&read_group);
}
_close(fd);
```

**Как это работает:**
1. Открывается файл в режиме чтения
2. Из файла читаются ровно `sizeof(StudyGroup)` байтов
3. Эти байты интерпретируются как поля структуры в памяти
4. При успехе структура полностью восстановлена

**Важно:** Десериализация работает корректно только если:
- Размер структуры те же (нельзя менять типы полей)
- Архитектура процессора та же (порядок байтов)
- Используется один и тот же компилятор (выравнивание может отличаться)

## 19. Что будет, если на место строки в текстовом файле записать другую строку большей или меньшей длины?

**При использовании буферизованного режима (fprintf/fwrite):**

1. **Если новая строка меньше старой:**
   ```
   До:  "Hello World\n"
   После: "Hi\n"
   Результат: "Hi\n World\n"  // остатки старой строки
   ```
   Остатки старой строки остаются в файле!

2. **Если новая строка больше старой:**
   ```
   До:  "Hi\n"
   После: "Hello World!\n"
   Результат: "Hello World!\n"  // ОК, новая строка переписывает старую
   ```

**При использовании `_lseek()` с небуферизованным режимом:**

Результат зависит от режима открытия:
- **`_O_TRUNC`** — файл полностью очищается перед записью
- **`_O_APPEND`** — всегда пишет в конец
- Обычное открытие — перезаписывает данные на месте

**Решение:** Обычно переписывают весь текстовый файл:
```c
// Читаем старые данные
// Модифицируем нужную строку
// Пишем всё заново в новый файл
// Удаляем старый файл и переименовываем новый
```

## 20. Как закрыть файл? Что при этом происходит с его дескриптором или указателем на FILE?

**Небуферизованный режим (дескриптор):**

```c
int fd = _open("file.bin", _O_RDONLY);
// ... работа с файлом ...
_close(fd);  // закрытие
```

**Что происходит:**
- Дескриптор освобождается и становится доступным для переиспользования
- Все несохраненные данные (если были возможны) теряются
- Ресурсы ОС, связанные с файлом, освобождаются
- Значение `fd` остается числом, но становится невалидным

**Буферизованный режим (FILE*):**

```c
FILE* file = fopen("file.txt", "r");
// ... работа с файлом ...
fclose(file);  // закрытие
```

**Что происходит:**
- Буфер FILE* очищается (flush)
- Все несохраненные данные записываются в файл
- Внутренний дескриптор автоматически закрывается
- Структура FILE* освобождается
- Указатель `file` становится невалидным (обычно остается на старом адресе в памяти)

**Важно:**

```c
// После закрытия файла:
_close(fd);
fclose(file);

// Нельзя использовать fd или file:
_read(fd, buffer, 10);  // ❌ Ошибка!
fprintf(file, "text");   // ❌ Ошибка!
```

**Хорошая практика:**

```c
if (file != NULL) {
    fclose(file);
    file = NULL;  // обнуляем указатель
}
```

Это предотвращает случайное использование закрытого файла.
